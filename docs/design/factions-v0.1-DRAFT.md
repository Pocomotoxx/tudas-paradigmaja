## A kilenc tudásváros

Minden város egy klasszikus Heroes III város szerepét „örökli", de teljesen
újragondolt, tudás-alapú identitással. A nevek fiktívek.

| Heroes III | Tudásterület | Új városnév | Karakter |
| --- | --- | --- | --- |
| Castle | Magyar nyelv és irodalom | **Academia** | kultúra, kommunikáció, vezetés |
| Rampart | Biológia | **Viridia** | élet, természet, regeneráció |
| Tower | Matematika | **Numeris** | logika, precizitás, technológia |
| Inferno | Kémia | **Catalyss** | reakciók, energia, átalakulás |
| Necropolis | Történelem | **Chronopolis** | múlt, stratégia, civilizáció |
| Dungeon | Informatika / digitális kultúra | **Nexum** | hálózatok, algoritmusok, információ |
| Stronghold | Földrajz | **Terranova** | tér, erőforrások, terjeszkedés |
| Fortress | Fizika | **Dynamis** | energia, mechanika, védelem |
| Conflux | Idegen nyelv | **Lingua** | kommunikáció, kapcsolatok, mobilitás |

## Városleírások és egységlétrák

### 1. Academia — Magyar nyelv és irodalom (Castle)
Alapelv: kommunikáció, kultúra, meggyőzés, vezetés. A nyelv a társadalmi
koordináció eszköze. **Egységlétra:** Írnok → Krónikás → Költő → Szónok →
Szerkesztő → Mesterbeszélő → Irodalmi Nagymester. **Specialitás:** morál,
diplomácia, szövetségkötés, információátadás, seregkoordináció. A „vezetői" város.

### 2. Viridia — Biológia (Rampart)
Alapelv: természet, élő rendszerek, alkalmazkodás, regeneráció. Futurisztikus,
bioinspirált civilizáció (nem mutáns szörnyek). **Egységlétra:** Sejtőr →
Botanikus → Zoológus → Genetikus → Ökológus → Biológus → Evolúciós Mester.
**Specialitás:** regeneráció, gyógyítás, alkalmazkodás, szaporodás, környezeti hatások.

### 3. Numeris — Matematika (Tower)
Alapelv: logika, számítás, geometria, valószínűség. Az egyik legerősebb,
leginkább technológiai város. **Egységlétra:** Számőr → Geometrista →
Algebraista → Statisztikus → Kalkulátor → Matematikai Konstruktor → Axiomatikus.
**Specialitás:** valószínűség-manipuláció, kritikus találat számítása,
pálya-optimalizálás, mozgás-előrejelzés. A „precíziós hadviselés" városa.

### 4. Catalyss — Kémia (Inferno)
Alapelv: laboratóriumok, reaktorok, katalizátorok, anyagtechnológia (nem tűz/démon).
Megtartja az Inferno agresszív, nagy sebzésű örökségét. **Egységlétra:** Laboráns →
Reagensőr → Katalizátor → Vegyész → Reaktormérnök → Molekuláris Mester →
Anyagalkimista. **Specialitás:** sebzés, átalakítás, mérgezés, korrózió, robbanás,
állapotváltozás.

### 5. Chronopolis — Történelem (Necropolis)
A „halottak városa" helyett a **múlt tudásának** városa — komor identitással, de
élő történelmi-kulturális rendszerként. **Egységlétra:** Levéltáros → Krónikás →
Régész → Történész → Haditörténész → Stratéga → Civilizációkutató.
**Specialitás:** korábbi eseményekből stratégiai előny (pl. elfoglalt terület
történelmi adatai bónuszt adnak). Ok-okozati gondolkodás, nem évszám-memorizálás.

### 6. Nexum — Informatika / digitális kultúra (Dungeon)
Alapelv: információs infrastruktúra (a Dungeon rejtett, technológiai jellege).
**Egységlétra:** Kódoló → Hacker → Algoritmista → Rendszermérnök → Kiberstratéga →
Hálózati Mester → Architekt. **Specialitás:** algoritmikus optimalizáció,
információszerzés, felderítés, rendszerzavarás, védelmi mechanizmusok, automatizáció.
Az „információs hadviselés" frakciója.

### 7. Terranova — Földrajz (Stronghold)
Alapelv: a **tér** (nem maga a „Föld") — erőforrás-orientált, terjeszkedő város.
**Egységlétra:** Térképész → Geológus → Kartográfus → Földkutató → Területstratéga →
Geopolitikus → Terraformátor. **Specialitás:** a legerősebb terep-manipuláció
(hegyek, folyók, utak, sivatagok, erdők). A tér feletti kontroll városa.

### 8. Dynamis — Fizika (Fortress)
Alapelv: energia, mozgás, erő, gravitáció, anyagviselkedés — a Fortress védekező,
pozicionális karakterével. **Egységlétra:** Mechanikus → Dinamikus → Energetikus →
Fizikus → Reaktormérnök → Kvantumkutató → Fizikai Mester. **Specialitás:**
kinetikus támadás, energiaelnyelés, gravitációs módosítás, mozgásbefolyásolás,
pajzsok, fizikai akadályok. A legjobb védekező/kontrolláló város.

### 9. Lingua — Idegen nyelv (Conflux)
Alapelv: kapcsolatteremtés és mobilitás (nem puszta „beszéd"). **Egységlétra:**
Nyelvtanuló → Tolmács → Fordító → Kommunikátor → Diplomata → Poliglott →
Lingvisztikai Mester. **Specialitás:** diplomácia, kereskedelem, információcsere,
ellenséges egységek meggyőzése, szövetségek, gyors területi kapcsolat, más
frakciókhoz való hozzáférés. A „soft power" város.

## Modell-következmények (a jelenlegi core-ra)

Ez a taxonómia **kibővíti és módosítja** a jelenlegi tárgy-modellt:

| Jelenlegi (5 tárgy) | Javasolt (9 tárgy) |
| --- | --- |
| `MATEMATIKA` | `MATEMATIKA` (Numeris) |
| `FIZIKA_KEMIA` (összevont) | **szétválik:** `FIZIKA` (Dynamis) + `KEMIA` (Catalyss) |
| `BIOLOGIA` | `BIOLOGIA` (Viridia) |
| `TORTENELEM` | `TORTENELEM` (Chronopolis) |
| `FOLDRAJZ` | `FOLDRAJZ` (Terranova) |
| — | **új:** `MAGYAR` (Academia) |
| — | **új:** `INFORMATIKA` (Nexum) |
| — | **új:** `IDEGEN_NYELV` (Lingua) |

**Érintett modulok a `Subject` enum bővítésekor:**
- `economy/KKLedger.ts` — a `Subject` enum és `ALL_SUBJECTS` (forrás-igazság).
- `world/LocationType.ts` — a `LABORATORY`/`OBSERVATORY` alapértelmezett tárgyai
  (pl. labor → `KEMIA`, csillagvizsgáló → `MATEMATIKA` vagy `FIZIKA`), új
  helyszín-típus-leképezések (pl. könyvtár → `MAGYAR`, adatközpont → `INFORMATIKA`).
- Tesztek, amelyek `FIZIKA_KEMIA`-t használnak (egységek, kérdések) → `FIZIKA`
  vagy `KEMIA`-ra bontandók.
- `RaschEstimator`, `KKLedger` snapshot-ok automatikusan skálázódnak az
  `ALL_SUBJECTS`-ből, de a mentés-formátum változik (9 kulcs) → save-verzió emelés.

**Új fogalom: egységlétra (unit tiers).** A jelenlegi `UnitTemplate` egyszintű; a
9 város 7-fokozatú létrát ad. Ez egy jövőbeli `tier`/upgrade-rendszert indokol a
`Recruitment`/`Unit` modellben (pl. `tier: 1..7`, fejlesztési lánc).
